# Matricula de Cursos Online

Prototipo fullstack para matriculas de cursos com frontend em Vue 3 e backend em Node/Express com TypeScript.

## Requisitos
- Node.js 18+

## Como executar

### Backend
```
cd backend
npm install
npm run dev
```

A API iniciara em http://localhost:3000.

### Frontend
```
cd frontend
npm install
npm run dev
```

A interface iniciara em http://localhost:5173.

## Scripts importantes
- Backend: `npm run dev`, `npm run build`, `npm run start`
- Frontend: `npm run dev`, `npm run build`, `npm run preview`
